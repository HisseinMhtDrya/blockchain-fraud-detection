Analyse d'une adresse Ethereum

L'analyse réelle récupère l'historique Ethereum via Etherscan et un RPC mainnet. Les noms, l'ordre et les transformations des caractéristiques sont partagés avec le modèle ; l'équivalence sémantique complète avec le corpus historique reste une limite documentée. L'analyse n'envoie aucune transaction sans autorisation explicite cochée.

Configurez ETHERSCAN_API_KEY et ETHEREUM_RPC_URL (chain ID 1) pour activer l'analyse réelle. Sans ces accès, utilisez la démo locale ci-dessous.

Un score expérimental n'est pas une preuve de fraude ou de blanchiment.
Démarrez le réseau local Hardhat pour activer cette simulation.
